# ragul.tech

Personal portfolio of Ragul Arumugam — built with zero frameworks, zero build tools, zero npm runtime dependencies.

## Stack

- `index.html` — semantic HTML5
- `style.css` — CSS3, custom properties, no frameworks
- `script.js` — vanilla JS, no libraries

## Run locally

Just open `index.html` in a browser. No build step required.

## Tests

```bash
npm install
npm test
```

Tests use [vitest](https://vitest.dev/) + [fast-check](https://fast-check.io/) + jsdom.
